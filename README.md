
# CS300 Assignment 3: JavaScript Data Toolkit

Name: Mohammed Oyeniyi

Scenario: Book Collection

Route: Console

## Project Description
This project helps users search, sort, filter, and organize a collection of books using JavaScript.

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Type `node harness.js`.
4. Press Enter to see the test results.

## Files
- toolkit.js: Contains the seven JavaScript functions.
- harness.js: Tests the functions and shows PASS or FAIL.
- data/books.json: Contains the book records.
